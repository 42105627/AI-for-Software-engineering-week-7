# AI Ethics Assignment – Designing Responsible and Fair AI Systems 

## Overview

This repository contains our group submission for the **AI Ethics Assignment** focused on designing responsible and fair AI systems. The assignment evaluates understanding of AI ethics principles, ability to identify and mitigate bias, and practical skills in auditing AI models using the COMPAS dataset.

**Theme:** Designing Responsible and Fair AI Systems
**Objective:** Build AI that is fair, transparent, accountable, and human-centric.

---

## Part 1: Theoretical Understanding (30%)

* Short Answer Questions:

  * Definition of algorithmic bias with examples
  * Transparency vs explainability
  * GDPR impact on AI
* Ethical Principles Matching:

  * Justice, Non-maleficence, Autonomy, Sustainability

---

## Part 2: Case Study Analysis (40%)

* **Case 1 – Biased Hiring Tool:** Identification of bias in Amazon’s recruitment AI, proposed mitigation strategies, and fairness metrics.
* **Case 2 – Facial Recognition in Policing:** Ethical risks and policy recommendations for responsible deployment.

---

## Part 3: Practical Audit (25%)

* **Dataset:** COMPAS Recidivism Dataset
* **Tools:** Python, Pandas, Matplotlib, Seaborn, AI Fairness 360
* **Tasks:**

  * Analyze racial bias using fairness metrics (disparate impact, false positive rate)
  * Apply mitigation (Reweighing)
  * Generate visualizations before and after mitigation

---

## Part 4: Ethical Reflection (5%)

* Group perspective on ensuring ethical AI in a smart data annotation tool
* Emphasis on fairness, transparency, accountability, and privacy

---

## Bonus Task (Extra 10%)

* **Policy Proposal:** Ethical AI use in healthcare
* Covers patient consent, bias mitigation, transparency, accountability, and continuous monitoring

---

## How to Reproduce Part 3 Audit

1. Clone this repository:

   ```bash
   git clone <repo-url>
   ```
2. Install dependencies:

   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn aif360
   ```
3. Open `fairness_audit.ipynb` in Jupyter Notebook or Google Colab.
4. Run all cells to replicate bias analysis and visualizations.
